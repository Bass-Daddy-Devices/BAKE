The first release of BAKE: an offline, node-based audio workstation for macOS 26 on Apple Silicon.

- Build a patch from nodes, wire modulation into any control, and bake it to a WAV that renders the same every time.
- Batch nodes run a patch over a whole folder of sounds.
- BAKE now checks for updates (Settings › Updates). Every update is signed and notarized.
